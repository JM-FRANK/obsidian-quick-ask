# Quick Ask 使用指南

**简体中文** · [English](user-guide.md) · [项目介绍](../README_zh.md)

配置、日常使用、图片规则、网络访问与本地数据的完整说明。

## 安装

需要**桌面版 Obsidian 1.13.7+**，不支持移动端。

从 Obsidian 社区插件目录安装：

1. 打开**设置 → 第三方插件 → 浏览**。
2. 搜索 **Quick Ask**，选择**安装**并启用。
3. 在 Quick Ask 设置中配置模型连接，然后提交问题。

手动安装时，从[已发布的发行版](https://github.com/JM-FRANK/obsidian-quick-ask/releases)下载 `main.js`、`manifest.json` 和 `styles.css`，复制到 Vault 的 `.obsidian/plugins/quick-ask/` 目录，再启用插件。如果自定义过 Vault 配置目录，请使用实际目录。已安装版本包含哪些改动，可查阅[更新日志](../CHANGELOG.md)。

## 求助与反馈

使用问题、缺陷或功能建议，请[提交 GitHub issue](https://github.com/JM-FRANK/obsidian-quick-ask/issues)。附上 Obsidian／插件版本、操作系统、请求协议和复现步骤；布局问题请附主题名称及截图。不要包含 API 密钥和私人笔记内容。

## 配置模型

打开**设置 → Quick Ask → 模型连接**，添加一组 **Base URL** 与**命名 API 密钥**，再选择模型，设置它的**请求协议**和**上下文窗口**。

- 根据服务支持情况，明确选择 **Responses** 或 **Chat Completions**。对于兼容的 `/v1` 端点，Base URL 不要追加 `/responses` 或 `/chat/completions`。出错后不会自动切换协议。
- 每份连接记住当前选用的模型，每个模型独立保存协议与上下文窗口。默认窗口为 **200K tokens**，请按服务实际容量配置。
- 地址与密钥均配置后，编辑其中任意一项会触发模型列表请求，也可点击“刷新模型”。打开设置、选择已有连接或重启不会获取模型列表。模型发现不发送笔记内容，保留已有选择与模型参数，也不代表已经验证生成兼容性；可以手工填写模型 ID。
- 原有单套配置会迁入默认连接。连接／模型的修改仅影响**新会话**；已有会话保留创建时的连接、模型、协议和容量，删除配置也不会改变它们。

设置分为**常规**、**模型连接**、**系统角色**、**网络搜索**、**外观**与**数据与备份**。模型 API 访问权限由你所选的提供方提供，插件本身不附带模型额度。

## 就笔记提问

1. 点击侧边栏图标，或运行“Quick Ask: 打开侧栏”命令。
2. 在 Markdown 编辑器中选中文字并拖入 Quick Ask，或通过 `[[`／文件浏览器拖入添加文件。使用全角标点时，`【【` 也可打开文件选择器。发送前可以检查或移除待发送的选区与引用。
3. 输入问题并发送。请求被接受后，加入的 Markdown 文件开始作为上下文被跟踪。模型可通过只读全文工具读取该会话中已加入的文件。
4. 回看会话时，回答与已提交选区一同保留。选区预览保存当时的原文，悬浮可查看全文；暂不提供点击打开或定位源文件的行为。

新发送的文字上下文包含来源行号及选区的字／词位置，不修改原始笔记；编辑器原始偏移仅保留在本地。重试问题同样使用当前固定提示词。默认角色不会在回答中输出行号细节，除非你明确要求。暂不支持 PDF 输入。界面支持英文和简体中文，仍有部分英文文字。

### 外观与工作区

在**外观**中调整用户／助手气泡配色、字号和段落间距，拖动输入区顶边可改变高度。状态栏与面板重叠时，Quick Ask 会在底部留出空间；主题已留出空间时不重复增加。

### 公式、图表与代码

回答结束后，公式与 Mermaid 代码块使用 Obsidian 渲染。公式字号保持不变，仅实际超出可用宽度时在公式底部叠加细横向滚动条，不改变公式高度；侧栏足够宽时自动隐藏，不预留滚动条位置。行内公式不显示工具栏；悬浮或聚焦独立公式后，点击右上角 **查看源码**（`</>`）即可选择、复制 LaTeX，再次点击恢复该公式。

Mermaid 图表右上角提供 **查看图片**、**查看源码** 与复制源码按钮。放大查看复用图片查看器，按 Escape 关闭；源码切换只影响当前图表。支持的图表语法随 Obsidian 版本变化，无法渲染时局部提示并显示源码。代码块（包括 text 和未标语言的代码块）、Mermaid 与 Markdown 表格统一在右上角提供复制按钮，悬浮或键盘聚焦时显示，成功后显示绿色勾约一秒。表格复制整张原始 Markdown，代码块复制块内正文、不含外层围栏；内容横向滚动时，按钮保持在可见区域。

### 角色、思考程度与压缩

在**系统角色**中选择、新建、重命名或编辑角色配置。初始提供文献阅读与学习出题，预设提示词统一使用英文；学习出题从三个问题开始。未编辑的旧版学习出题预设会升级为英文，已编辑提示词及已有会话保留其保存的文本。自定义提示词替换内置的阅读角色，固定的工具、只读及公式／图表格式规则保留。所选角色用于新会话，已有会话保留其保存的角色。

点击思考程度文字，循环选择 **Off / Low / High / XHigh / Max**，也可使用切换思考程度命令。默认 **High**，修改影响下一问，实际支持情况由提供方决定。API 返回可读推理时，界面会显示相应内容。

在输入区键入 `/` 可选择 `/compact`、`/web_search` 等操作。自动或手动压缩会缩短发送给模型的上下文，不删除本地对话历史；受跟踪文件仍可由允许的全文工具读取。未发送的联网／思考程度选择只保存在内存中，不跨插件重启保留。

### 图片

通过 `[[`、Vault／外部拖入或剪贴板粘贴添加 **PNG/JPEG/WebP**，允许只发图片。单张最多 **20 MiB**，每次最多 **20 张**、总计 **200 MiB**；原样发送，不缩放或压缩。

图片字节只发送到该问题的首次模型请求，工具续接、后续问题与压缩不重发；显式重试会重新读取图片源。历史与导出只保存路径，不包含图片文件；预览显示当前源文件，缺失时显示占位。

外部与粘贴图片会复制到插件缓存，Vault 原图不会复制。**保存缓存图片**默认开启；关闭后，在下次重新打开 Obsidian 时清理缓存，插件重载不清理。图片不计入本地 token 估算，实际计费以提供方返回的用量为准。

### 网络搜索

联网**默认关闭**，默认搜索服务为 **DuckDuckGo**。通过地球按钮或 `/web_search` 为问题开启联网。在**网络搜索**设置中可调整默认行为，并选择 **Firecrawl**、**Exa**、**Parallel**、**Perplexity Search** 或**模型提供商的服务端搜索**。独立 API 服务需单独配置凭据。

提供商搜索支持可用的 Responses／Chat Completions 路由、DeepSeek 独立 Search API、Gemini 原生 API Key 搜索及 CPA/Antigravity 等受支持中转。Google 联网轮保留你明确加入的上下文，但不使用本地文件工具。搜索方式由你手动选择，失败不会悄悄切换服务。端点和凭据配置见[厂商联网搜索配置](native-search.md)；可用性、流式输出及结构化来源信息取决于所选服务。

## 账号、费用与网络使用

Quick Ask 免费，不需要 Quick Ask 账号。模型／搜索提供方可能要求账号、API 密钥或付费额度，其费用另行计算；AI 聊天订阅不一定包含 API 访问权限。

提交问题时，提示词、选中的段落、引用文件内容及有效会话上下文会发送到你配置的服务。后续模型／工具调用可能发送已加入文件的最新版本或完整内容；上下文计数或压缩也可能访问该服务。开启联网后，还可能访问所选搜索服务。模型发现发送带鉴权的模型列表请求，不包含笔记内容；恢复／删除较早版本保存在提供方的响应时，也可能访问其配置端点。

仅打开或启用侧栏不会提交笔记内容。插件没有遥测、分析、广告或开发者运营的后端，不会自行安装更新或在运行时下载可执行依赖。发送数据适用提供方的保留与隐私政策。

## 本地数据与隐私

- `data.json` 保存偏好设置及**命名密钥引用**，不保存 API 密钥值；密钥值来自 Obsidian 密钥存储。
- 会话及加入的文字上下文以可读、追加式 JSONL 文件保存在插件目录的 `quick-ask/` 子目录中，本插件不加密本地历史。
- **数据与备份**提供会话导出／导入、数据清理，以及写入指定 Vault 文件夹的可选明文保留副本。导出不含密钥值，图片只保留路径而非字节。
- 文件选择器枚举 Vault 路径并排除配置目录，不会因此读取或发送所有文件正文；只为明确加入的上下文和已跟踪文件读取内容。
- 剪贴板访问由用户主动触发：粘贴图片读取粘贴事件，导入读取剪贴板文字，复制／导出写入所选内容。插件不后台轮询或监视剪贴板；导入会话也不会自动提交给提供方，需你发送问题。
- 外部图片拖入只读取你明确提供的文件并复制到插件缓存，不扫描外部文件夹；提交对应问题时才发送图片。
- Vault 同步和备份工具可能按各自配置复制插件数据。

## 开发

本仓库是由 Scholar Workbench 生成的独立发行仓库。功能和文档修改在上游源码项目维护，再同步到这里；流程见[维护说明](maintaining.md)。

使用 **Node.js 22.12+** 构建和检查本地副本：

```sh
npm ci
npm run build
npm test
npm run check
```

从 Scholar Workbench 内置版切换时，导出／导入会话、配置模型连接与密钥，并关闭内置 Quick Ask；两个插件的会话存储互相独立。
